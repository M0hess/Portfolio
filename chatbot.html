Chatbot IA

Développement d’un chatbot utilisant un modèle IA via Ollama avec une architecture full-stack moderne.

Technologies utilisées

  • Vue.js (Frontend)
  • Express (Backend)
  • Bun (Runtime)
  • MongoDB (Base de données)
  • Ollama (Modèle IA)

Fonctionnalités

  • Chat en temps réel avec IA
  • Gestion des conversations
  • Stockage des messages en base de données
  • Interface utilisateur responsive

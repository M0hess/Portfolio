Site E-commerce

Développement d’un site e-commerce complet avec Laravel, incluant gestion des produits, utilisateurs et commandes.

Technologies utilisées

  • Laravel (Backend PHP)
  • Blade (Templates)
  • Sqlite (Base de données)
  • Tailwind CSS (Frontend)

Fonctionnalités

  • Gestion des produits
  • Panier utilisateur
  • Système de commande
  • Authentification utilisateur
  • Interface d’administration

Architecture du projet

Le projet suit une architecture MVC avec Laravel :

  • Frontend : Blade + Tailwind CSS
  • Backend : Laravel (Controllers, Models, Routes)
  • Base de données : Sqlite pour stocker utilisateurs, produits et commandes
